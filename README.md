# Vacation Scheduler

An Android application developed in Java for managing vacations and associated excursions.

Originally developed for an Android programming course and later expanded for my Software Engineering Capstone.

## Features

- Create, view, update, and delete vacations and excursions.
- Associate excursions with specific vacations.
- Store and retrieve information using a local Room database.
- Display vacation and excursion records using RecyclerView adapters.
- Navigate between vacation and excursion detail screens.
- Manage date-related information and notifications.

## Technologies Used

- Java
- Android SDK
- Android Studio
- Room Persistence Library
- SQLite
- Gradle
- XML layouts

## Application Architecture

The application uses Java classes to represent vacations and excursions, with Data Access Objects (DAOs) providing database operations.

A repository coordinates access to the Room database, while Android activities manage user interactions and display information through RecyclerView adapters.

## Project Background

This application was independently implemented as part of my software engineering education and subsequently expanded for my capstone project.

The project demonstrates Android application development, object-oriented programming, relational data modeling, local data persistence, and user interface development.
